# Parallens 桌面数据看板原型

本仓库是静态网页原型，数据均为演示用模拟数据。当前分享地址：https://sailorxsh.github.io/parallens-demo/ 。

筛选校验：共享链接中本页支持的筛选字段出现未知值、空值、多个值或不兼容组合时，保留条件并暂停全部指标、图表、结论及新问题登记；页面提供修正和逐项清除入口，重置全部可恢复默认范围。适用于当前页的无效条件随导航和指标查找保留，刷新及前进后退重新校验；其他页专属字段和非筛选参数沿用原路由规则。有效条件下的“不适用”“待补数据”保持区别；已有本地问题记录与草稿不被改写。首页设备结构和行动卡片也按指标适用范围说明：未应用的条件明确列出，全部忽略时标为本项总体；缺少明细时显示具体缺口，不再声称已作分片估算。业务定义保留，只有已算出结果的适用范围才标注模拟分片或合成事件来源。

时间口径：完整周成熟批次为 W1–W12，截止 2026-09-13；当前经营快照截至 2026-09-24。历史经营快照是每隔7天构造的演示序列，不能当作 W1–W12 的实际批次历史。统计周仅显示在有周度事实的诊断页，不套用到快照指标。尚无可核验的任意日期区间事实，因此原型不提供自由日期范围。

D页批次可用性：按快照2026-09-24演示9月27日批次“观察未结束”、9月20日批次“结果待齐”。独立合成分组的应齐/已齐人数放在 trial-facts.json 的 readiness 中，业务筛选沿用试用转正指标；统计周不控制这些后续批次。尚未观察完或结果未齐时不核算转正率，也不进入现有12,000条成熟明细的分母。未覆盖的筛选组合显示暂无样例，不能推断没有待齐批次。分组核对可展开，计数不代表真实生产数据；上线需批次日历、结果回流完整性及同范围明细。

D页失败样本：显示当前完整周成熟试用人数及支付失败条数；Free不适用或没有成熟记录时数量显示“—”，不显示假零。低样本记录保留供核对，不能作为新问题单的指标基线；可用范围仍可关联记录、保存并刷新恢复。保存环节同样校验新记录基线；已有历史记录仍可编辑并保留原基线。分组图说明当前选择及未绘制分组的原因，不将不可用比例补成0。

首页组合布局：从上至下为经营简报、经营结果、变化线索与行动解读、六节点经营主线。经营结果采用四列指标栏，变化标签与比较日期同一行；净增以期初存量为基准显示变化比例，同时保留期初→期末人数。其余三个结果指标比较相邻模拟快照，不混用完整周批次。变化区左侧图表、右侧分析，选择线索同步图形、观察与分组证据入口，比较依据在原位展开；切换线索保留键盘焦点。六节点保留默认趋势与各自环比，N3/N4/N5用橙色顶边突出；补充订阅状态、设备结构与行动入口继续可查。

首页变化线索：7日价值激活比较前8周与近4周，试用转正比较前9周与近3周；分别合并分子、分母后计算变化，不按跨阶段人数排序。点击线索可聚焦趋势、前期基准与近期区间，再进入相应专题核对证据；“并列对照”可恢复两条趋势。筛选后的演示估算与合成明细来源在比较依据中标明。试用转正解读与D页复用同一互斥分组贡献计算，直接给出主要分组及百分点贡献；其余分组存在变化时同时交代合计，保留数学分解不证明因果的边界。批次或分组样本不足30、变化基本持平或依据不一致时不生成强分组线索，不把变化乘单周分母当成实际损失人数。

指标口径：关键指标卡、目录和当前证据标题旁均可点同款弱化的i入口，显示原指标的定义、计算方法、数据粒度及来源。浮层保留浏览器顶层显示，宽度随文字尺寸变化，标题与关闭按钮固定、正文独立滚动；Esc或关闭回到原入口。原入口仍可见时不移动阅读位置，文字／窗口变化使其离开视口时再显露焦点；不改变筛选、证据、登记基线或草稿。

诊断阅读主语：A–G右侧优先解释当前左侧指标，登记入口标明同一指标编号与名称。已有可核验规则保留变化解读及计算依据；没有规则时仅显示事实摘要、统计窗口、适用筛选及已有历史变化，明确暂无诊断结论。其他指标的本页重点观察放在独立的“本页重点观察”展开入口，点击其证据后才切换阅读对象；查看证据不切换已有问题单。共享指标（如E页MRR）与本页自有指标的草稿、已保存问题均可在同范围问题选择器中找回，原基线及存储格式保持不变。

设备变化诊断：C页#42的“分组证据”先展示与右侧比较周期一致的互斥组合贡献，之后保留最新周的型号水平。默认前8周→近4周总体42%→58%，K6·固件2.8贡献+16个百分点、其他型号／固件组合0；选择统计周后改为相邻两周。贡献以同期总体触发数为分母，组内率与触发构成在独立验算入口核对；构成变化与组内变化采用两期平均权重分解，合计回到总体变化。观察链接直达分组变化证据，不更换既有问题单。上升空触发率标为不利；首周、缺少同范围计数或低样本分组不构造贡献。所有计数仍为合成样本，数学贡献不证明固件故障因果，也不把型号分配推广为真实经营判断。

专题观察：A、C、D 的比率比较展示前后值、百分点变化及可展开的周期和分子/分母。首页与专题共用按人数或事件次数合并的计算入口；专题选择统计周后比较相邻完整周，第一周或样本不足时不生成变化。估算范围与合成事实来源随筛选说明，不把跨期变化乘以单周分母写成实际损失人数。

图表核对：趋势末端与单序列分组柱直接标出数值；悬停保留单位，有逐周事实的比率同时显示分子、分母，并在完整数据表中给出相同依据。折线趋势按实际值域生成纵轴刻度，图下注明范围及非零起点；事件丢失率的默认演示范围为1.6%–2.4%，筛选后重新计算。普通比例分组柱保留零起点，按当前数据设置上限并注明范围，避免低比例被固定100%压平；同图各组共用刻度，隐藏系列不改变刻度，跨图比较需看实际比例而非柱高。指定刻度的技术图、100%结构图和热力图保留原规则。诊断工作区按趋势、分组与完整数据切换；图表下方可展开对应验算表，放大阅读或缩窄桌面窗口时按可用空间重新排列。100%结构图保持全部互斥类别展示，热力图统一使用0–100%色阶。

多系列图例：可切换的趋势/分组图例使用标准按钮，鼠标、Enter和空格均可显示或隐藏系列，按钮状态与ECharts保持一致。完整数据表和比较刻度不随隐藏操作改变；全部隐藏时明确提示恢复。折线以实线/虚线/点线与不同点形辅助区分；首页转正线在单独查看与并列对照中均保持绿色虚线。百分比堆叠图的固定状态图例继续不可切换，避免破坏100%结构解读。切换指标或业务筛选后图例恢复默认显示。放大桌面文字时侧栏宽度随文字尺寸增加，窄桌面窗口的首页趋势与分析转为单列，避免把图表挤窄；正常桌面的左右比例保留。

分类柱图按实际字体、文字放大比例与绘图区宽度判断标签是否能水平放下；短名称水平显示，保留显式指定的长标签角度，并按文字边界预留轴标签及图例空间。窗口或组件宽度改变后重新计算，不缩小字号，不改变类别、数值、零基线、图例选择或完整数据表。

订阅状态核对：D页#5直接打开两条产品线的当前状态100%堆叠图，与首页共用状态颜色和源人数。每条以自身主账号总数为分母，较大区段直接标占比；试用前期与临期在图中合并，完整值表分别保留。悬停及图表数据表显示精确状态人数与产品线人数，点击区段展开对应产品线验算行。缺数据或零总体不绘制已知比例，也不构造快照的历史趋势。完整值表只移除整列空内容，保留有效数值、分子分母及文字；仅有结果的比例项明确说明没有同口径分子分母明细。

未使用与回流：#29分别展示截至2026-09-24的当前未使用池，以及独立历史入组人群随后7天的回流；两行明确各自分母和窗口。历史入组日期未提供，不比较跨期趋势或归因召回效果。回流分母独立应用30人演示规则：少于30人保留人数、标为样本不足，零分母显示无历史样本，不影响仍有充分分母的当前未使用率。另一组600/5,000回流样例保持原人数，单独说明入组日期及回流窗口缺失；不与7天样例合并。问题登记继续使用当前未使用率与快照基线。宽表横向滚动时，标题、滚动提示与计算说明留在可视范围。

指标摘要：卡片主值明确标注统计对象和单位；累计注册与当前绑定、DAU与WAU/MAU、订阅ARPPU与月内付款人数、事件丢失率与ID映射覆盖率分别展示。目录和口径保留底表原名称；摘要与完整值跟随各自适用的筛选条件，不适用时不显示虚构人数。多设备主账号占比可进入12期趋势与验算表；多设备占比和共享率上涨仅标注变化，不自动判为改善。

付费价值变化：E页#35观察按最近两个完整月的订阅净收入比较。付款人数变化与ARPPU变化采用两期均值作对称算术分解，两项合计回到收入净变化；默认7月→8月为+$2,020＝人数项+$1,030＋ARPPU项+$990。观察可展开两期人数、收入与ARPPU，点击证据进入贡献柱图与验算表。贡献不是价格或业务因果判断，与MRR分开；筛后仍为模拟分片估算，低样本或不支持范围不生成拆分。

E页默认#35观察直接展示两期月内订阅付款人数与ARPPU及各自变动，区分指标本身变化与收入贡献金额；数字共用同范围月度比较来源，筛选后更新。持平、下降分别呈现；不足美分的ARPPU变化说明显示精度，不将其写成完全持平。缺少可比事实时不保留总体比较，登记草稿及历史基线仍沿用原规则。

A–G诊断工作区：顶部保留四张关键指标卡；左侧约2/3宽度切换趋势与变化（E为变化拆分）、分组证据与完整数据，右侧保留当前观察并在原位打开问题单。F默认聚焦多设备占比的12期历史，E默认聚焦#35收入变化；其他指标按可用趋势、分组或完整值展示。D的批次可用性默认随成熟趋势展示，试用支付样本、C设备样本、G异常事件样本在分组证据中核对。原有订阅流转、技术链路、付费结构、型号对照、完整表和行动清单保留；验算表与补充趋势按需展开，隐藏图表在打开时绘制。标签写入URL，刷新和前进后退恢复选择；打开其他指标依据时自动选择其可用证据视图，避免沿用“完整数据”而隐藏趋势。观察登记关联其证据指标，查看辅助证据或切换右侧视图不更换当前问题、不丢失草稿；各页完整指标目录可展开，全局查找继续覆盖全部指标。

分组证据定位：同一标签内有多块独立证据时提供标题入口，点击或键盘操作可直接定位并展开对应模块，保留筛选、问题单及草稿，标题不会被固定导航遮住。D页两批次转正率采用局部横轴点图，显示各自比率及分子/分母，图下注明范围；点图点击可打开对应数据行，小样本不绘为0。左右并排时关联试用样本只更新右侧问题单，保留左侧证据DOM、当前指标和视野；原问题的草稿与登记基线可切回查看。Chrome与WebKit在1366×768、1600×900、1920×1080验证导航、真实点选及样本登记。C设备样本与G异常事件使用列表、详情并排视图，列表独立滚动；正常桌面查看和选择样本时，核对建议与关联指标入口保持可见。选中反馈使用现有无障碍播报区，保留当前问题单、筛选与登记基线。

指标证据默认落点：优先展示所选指标自己的趋势或图示；只有完整数值时直接打开该指标的数据表，专题的其他图表和样本不决定默认标签。已核实归属的首图箱线、订阅流转、设备交叉状态保留图示入口；设备交叉状态的对应补充区自动展开。用户明确选择的标签、刷新与阅读历史继续保留，辅助证据不替换当前问题单。

技术链路：上传、直播、推送独立展示成功率，默认主值明确标为三者最低；选择功能后只显示该链路。摘要和核对区给出各自请求数、成功数、失败数与失败率，柱图从0开始。型号×固件按最近24小时合成请求明细聚合，设备状态仍属模拟分片估算，分别说明来源；没有可比历史或生产目标时明确标注，不虚构趋势或达标结论。

订阅流转阅读：D页以点表示期初/期末存量、浮动柱表示各环节增减，直接标出存量和带符号的变动，用虚线连接累计水平；图下注明局部纵轴与完整人数等式。默认12,020＋530＋120＋90－360＝12,400，净增380，与首页一致；观鸟、狩猎分别按合成流水核对，其他适用筛选仍明确为模拟分片估算。点选期末可展开对应验算行，不切换问题单或草稿。如果同范围期末超过期初加全部新增，明确显示数据不闭合并暂停计算净增。首页订阅状态表在1366、1600、1920桌面宽度默认显示全部8列；放大阅读时保留可发现的键盘滚动，行/列标题有明确语义。

数据质量入口：页头状态使用当前范围的#54指标计算；缺少筛后质量明细时显示“待补数据”，不会沿用总体的正常标记。默认范围以事件丢失率≤3%、ID映射覆盖率≥95%的演示阈值判定，明确标注“演示正常/演示预警”；缺少可核验比率或阈值时显示“待核验”。点击直接进入同范围质量指标证据，G页提供既有业务适用维度App平台的筛选入口，跳转保留平台选择；摘要与核对区说明阈值并区分生产标准。

计数单位由指标含义统一确定：人数用“人”、设备用“台”、异常事件用“条”，卡片、目录与分组图一致；时间粒度不作为计数对象。首页行动入口同样显示计数单位；未使用池与Free权益用满池注明主账号，显示与专题率同源的去重人数。两个入口名称可直接通过指标查找定位原指标。多设备主账号占比使用2026-09-24当前绑定关系快照，分母为绑定主账号，不标为完整月流量。

质量指标证据同时呈现已有7日丢失率趋势和逐日丢失/预期事件数，悬停与表格使用同一分子、分母，纵轴按值域并注明非零起点。ID映射覆盖率只有当前快照，明确说明无可比历史；缺少同范围质量明细时仍显示待补数据，不拼接总体趋势。

桌面阅读：专题指标名称使用13px，变化提示、统计窗口、子项和摘要说明使用12px的相对字号。长名称平衡换行，详情为数值和说明分配更多宽度；浏览器不支持优化换行时保留普通换行。正常桌面仍并排呈现短指标，放大阅读时按可用宽度排列。首页订阅状态与设备结构在阅读空间不足时上下排列，行动卡片随文字尺寸由四列降为两列，极窄阅读空间再为单列；以卡片阅读宽度、图例和坐标文字互不遮挡验收。

专题首屏：编号并入指标标题行，关键指标与主趋势区保留语义标题、去掉重复装饰编号，压缩页头和比较区的空白。默认1366×768、1600×900、1920×1080下可完整看到A–G的关键观察标题及A/C/D的前后率与百分点变化；保留原有字号、子项、口径入口和默认趋势，不要求全部图表挤入首屏。展开详情或筛选后的长说明可自然增加页面高度。

图点核对：首页趋势点可展开对应周的数据，并标亮所选指标列；订阅状态色带标亮对应产品线和状态人数，提示保留精确人数与占比。切换趋势或图例清除旧选中提示，筛选变化后不沿用旧范围的选择。诊断图表的数据点可展开相邻核算表并标亮对应行；热力图提示所选型号及活跃／订阅维度，人数直接取自型号主账号源计数，保留原生键盘展开入口。点选只属于图内临时查看，不修改全局筛选或问题单。堆叠色带按实际鼠标位置与精确比例定位，避免WebKit点击坐标舍入选中相邻窄色带；不扩大色带宽度。折线数据点为6px，避免小点边缘首次点击只命中线条。

诊断阅读位置：用鼠标或键盘切换证据标签时保留页面位置，面板缩短时按浏览器可滚动范围收敛。章节提示在前一章节标题已滚出后按主要可见内容更新；主动定位关键指标、诊断工作区或全部指标以及浏览器返回／前进仍沿用各自落点。

指标查找：保留底表名称和业务问题，同时识别卡片名称及DAU/WAU/MAU、技术链路、质量监控等子项。多个关键词以空格分隔共同匹配；全角编号和英文大小写统一处理。别名命中时显示匹配项，仍进入原指标证据并保留目标页支持的筛选；搜索不因当前筛选缺少数据而隐藏对应指标。

行动复查：点击指标摘要或数据核对中的“登记该指标问题”，显式打开当前指标＋筛选范围的问题单；查看辅助证据不自动切换。专题允许引用的共享指标也可在该专题登记，URL、基线及复查指标随当前问题保持一致。本范围的问题单可切换已有记录和未保存草稿，原记录键与历史基线保持不变。试用支付样本明确关联到试用转正问题单。清单条目分别关联对应指标依据；筛后核对表与卡片共用指标摘要，保留各子项名称、单位与窗口，点击指标可查看同范围证据。辅助证据跳转保留当前问题单和草稿。问题单按指标实际完整周、完整月或快照登记基线。登记与复查分组展示，人工确认通过需填写验收条件、实测值和实际复查日，不代表系统自动验算达标。记录仅存于当前浏览器，未保存内容切页暂存、刷新丢失；存储失败时保留原记录并明确提示失败，研判标记与问题单复查进度分开登记。

新问题单的基线保留指标摘要中的子项及单位；例如#35同时登记订阅ARPPU、月内付款主账号、订阅净收入与完整月份，三项随适用筛选计算。DAU/WAU/MAU、累计/当前绑定设备、各技术链路和质量比率也分别标明。已有记录和未保存草稿继续沿用其登记时的基线，不用当前值覆盖历史。

问题单状态：编辑、撤回编辑和保存后，选择器立即同步“未保存草稿／已保存”，状态放在指标名称前，并保留完整悬停文字。保存失败仍明确标记草稿；不更新原登记基线或其他范围的记录。首页结果列数按实际内容宽度调整，空间足够时四项同排，放大文字后保留自动换行。

跨范围问题查找：侧栏“已登记问题”集中显示本浏览器已保存的A–G问题，支持按指标、问题编号、范围、负责人或处理状态查找，并显示计划复查日。打开后替换为原登记筛选、进入原指标问题单，保留原编号、历史基线、状态及会话草稿；查看列表不会保存或修改记录。独立行动清单的研判标记不混入问题列表。旧记录缺少筛选快照、范围标识不一致或含已不支持的条件时，保留只读详情及原因，不自动替换成总体；没有迁移或重写原存储格式。原生顶层弹窗支持键盘打开、关闭和焦点返回，宽表复用滚动提示与方向键。

复查填写反馈：提交后在各错误字段旁显示具体提示，并将焦点移到第一项；补填其中一项或编辑处理说明，不覆盖其余字段的错误说明。实际复查日不得早于原登记基线的统计期末，也不能晚于今天；完整周取原周结束日，完整月取原月末，快照取原快照日，不用当前筛选或新数据替换历史边界。无法识别的旧窗口只提示人工核对，不推定最早日期；旧记录不会自动改写，已有日期矛盾会提示更正。切回待处理／核查中后，已不必填的空复查字段清除过期错误；已填写的无效日期仍需修正。填写中清除当前项的旧提示，保存时继续完整校验，保存状态与字段错误分别展示；不再叠加浏览器验证气泡。该检查仅验证日期先后，是否达标仍由人工确认。

复查长文本：验收条件与复查实测值在问题单内各占完整阅读宽度，支持多行输入和Enter换行；保存仍由原按钮执行。支持field-sizing的浏览器按内容增长至上限，超长内容在框内滚动；其他浏览器保留三行文本框和原生纵向调整。原字段、草稿及保存格式不变，旧记录换行不会因读取而被改写，也不会误判为未保存编辑。

设备空触发：周×型号×固件合成事件计数是卡片、趋势、比较、分组和完整表的共同来源。原有每周总体与 K6 固件2.8 分组保留；其他型号拆分为构造样本，不作实测或因果结论。国家与季节仍为业务适用筛选，缺少交叉明细时显示待补数据。

经营核查：首页“核对分组证据”直接进入所选指标的分组页签；明确指标后修改筛选，保留当前分组或完整数据视图。D页以同一期总体成熟试用人数为分母展示互斥分组贡献，合计回到总体转正率变化；图、表、观察共用观鸟Android Plus月付分组规则。小样本不展示可靠贡献，单周选择不保留跨期比较；同步变化与数学分解不作为因果结论。

加载体验：主内容框架阻止加载卡片外边距折叠，并为完整桌面视口保留高度，避免初始化时主内容和页脚跳动。17组数据最多6个并发，完成一个就补上一个，全部准备齐再呈现看板；进度、失败重试及原URL中的筛选、指标和问题单保留。失败时先等待已发出的请求结束，再开放重试，避免旧请求干扰新进度。

图表等待恢复：17组数据齐备而图表资源仍在等待时，可选择“先查看数据表”。专题直接打开已有完整数据页签，首页展开12周趋势表；数据不完整或失败时不开放入口。图表稍后成功或失败都不自动重绘当前页面，保留草稿和阅读位置；用户主动切换或导航时可恢复图形。首页缺图提示不占整块图形空间、不显示无对应图形的纵轴说明，让表格保持可发现。

图表资源：本地ECharts仍为5.5.1，按实际使用保留折线、柱、散点、箱线、热力图及SVG渲染、图例、提示、标记线／区间与标签布局。按需包约623KB，版权和依赖声明随包保留；页面不请求外部图表CDN。普通发布仍直接复制已提交资源，无新增在线构建依赖。新增图型时先更新`scripts/chart-library-entry.mjs`并复建、验证。

字体资源：DM Sans优先使用本地完整WOFF2（88,820字节），保留原TTF与OFL许可作为来源及加载回退；没有删除字符、字重或字距功能。可在装有`fonttools[woff]`的本地Python环境运行`scripts/build_font.py`复建，脚本验证字符、字形、提示与字体表一致。普通发布直接复制已提交字体，不安装字体工具或改变CI流程。

手动复建图表包：在项目之外的临时目录准备固定版本，再将其`node_modules`路径交给脚本。它校验ECharts、ZRender、tslib和esbuild版本，避免意外升级；同版本复建结果可用SHA-256核对。

```sh
npm install --prefix /tmp/parallens-chart-build --ignore-scripts --no-audit --no-fund echarts@5.5.1 esbuild@0.25.11
node scripts/build-chart-library.cjs /tmp/parallens-chart-build/node_modules
```

模拟数据重建：基础生成器保留周×型号×固件触发计数；筛选策略生成器保留空触发指标国家/季节待补明细的边界。运行 `python3 scripts/verify_event_generation.py` 会在临时副本中核对10份基础/策略文件与当前数据一致，并确认已审阅的目录、口径及专题证据没有被覆盖。

人均金额变化：订阅ARPPU卡片、趋势辅助阅读文本和收入分析保留相同的美分精度；真实小幅变化不套用比率的持平阈值。显示变化不足半美分时注明“上升／下降不足 $0.01/人”，保留方向；半美分边界按美分显示。缺少或不足30人的上期分母时显示暂无可比值，不推定持平。

# Parallens 桌面数据看板原型

本仓库是静态网页原型，数据均为演示用模拟数据。当前分享地址：https://sailorxsh.github.io/parallens-demo/ 。

时间口径：完整周成熟批次为 W1–W12，截止 2026-09-13；当前经营快照截至 2026-09-24。历史经营快照是每隔7天构造的演示序列，不能当作 W1–W12 的实际批次历史。统计周仅显示在有周度事实的诊断页，不套用到快照指标。尚无可核验的任意日期区间事实，因此原型不提供自由日期范围。

首页变化线索：7日价值激活比较前8周与近4周，试用转正比较前9周与近3周；分别合并分子、分母后计算变化，不按跨阶段人数排序。点击线索可聚焦趋势、前期基准与近期区间，再进入相应专题核对证据；“并列对照”可恢复两条趋势。筛选后的演示估算与合成明细来源在比较依据中标明。

专题观察：A、C、D 的比率比较展示前后值、百分点变化及可展开的周期和分子/分母。首页与专题共用按人数或事件次数合并的计算入口；专题选择统计周后比较相邻完整周，第一周或样本不足时不生成变化。估算范围与合成事实来源随筛选说明，不把跨期变化乘以单周分母写成实际损失人数。

图表核对：趋势末端与单序列分组柱直接标出数值；悬停保留单位，有逐周事实的比率同时显示分子、分母，并在完整数据表中给出相同依据。指标数据核对区的补充趋势、常规分组图与各自验算表并排呈现；放大阅读或缩窄桌面窗口时按可用空间重新排列。100%结构图保持全部互斥类别展示，热力图统一使用0–100%色阶。

行动复查：清单条目分别关联对应指标依据；问题单按指标实际完整周、完整月或快照登记基线。登记与复查分组展示，人工确认通过需填写验收条件、实测值和实际复查日，不代表系统自动验算达标。记录仅存于当前浏览器，未保存内容切页暂存、刷新丢失；存储失败时保留原记录并明确提示失败，研判标记与问题单复查进度分开登记。

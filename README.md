新问题单在原baseline文字字段保存来源版本、计数、配置／批次／观察窗；已登记问题入口可读这些证据并恢复所选范围。旧编号、范围、原基线、比较证据和草稿不迁移；更新进度保留首次证据。


筛选校验：共享链接中本页支持的筛选字段出现未知值、空值、多个值或不兼容组合时，保留条件并暂停全部指标、图表、结论及新问题登记；页面提供修正和逐项清除入口，重置全部可恢复默认范围。适用于当前页的无效条件随导航和指标查找保留，刷新及前进后退重新校验；其他页专属字段和非筛选参数沿用原路由规则。有效条件下的“不适用”“待补数据”保持区别；已有本地问题记录与草稿不被改写。首页设备结构和行动卡片也按指标适用范围说明：未应用的条件明确列出，全部忽略时标为本项总体；缺少明细时显示具体缺口，不再声称已作分片估算。业务定义保留，只有已算出结果的适用范围才标注模拟分片或合成事件来源。

时间口径：完整周成熟批次为 W1–W12，截止 2026-09-13；当前经营快照截至 2026-09-24。历史经营快照是每隔7天构造的演示序列，不能当作 W1–W12 的实际批次历史。统计周仅显示在有周度事实的诊断页，不套用到快照指标。尚无可核验的任意日期区间事实，因此原型不提供自由日期范围。

D页批次可用性：按快照2026-09-24演示9月27日批次“观察未结束”、9月20日批次“结果待齐”。独立合成分组的应齐/已齐人数放在 trial-facts.json 的 readiness 中，业务筛选沿用试用转正指标；统计周不控制这些后续批次。尚未观察完或结果未齐时不核算转正率，也不进入现有12,000条成熟明细的分母。未覆盖的筛选组合显示暂无样例，不能推断没有待齐批次。分组核对可展开，计数不代表真实生产数据；上线需批次日历、结果回流完整性及同范围明细。

D页失败样本：显示当前完整周成熟试用人数及支付失败条数；Free不适用或没有成熟记录时数量显示“—”，不显示假零。低样本记录保留供核对，不能作为新问题单的指标基线；可用范围仍可关联记录、保存并刷新恢复。保存环节同样校验新记录基线；已有历史记录仍可编辑并保留原基线。分组图说明当前选择及未绘制分组的原因，不将不可用比例补成0。

首页组合布局：从上至下为经营简报、经营结果、变化线索与行动解读、六节点经营主线。经营结果采用四列指标栏，变化标签与比较日期同一行；净增以期初存量为基准显示变化比例，同时保留期初→期末人数。其余三个结果指标比较相邻模拟快照，不混用完整周批次。变化区左侧图表、右侧分析，选择线索同步图形、观察与分组证据入口，比较依据在原位展开；切换线索保留键盘焦点。六节点保留默认趋势与各自环比，N3/N4/N5用橙色顶边突出；补充订阅状态、设备结构与行动入口继续可查。

首页变化线索：7日价值激活比较前8周与近4周，试用转正比较前9周与近3周；分别合并分子、分母后计算变化，不按跨阶段人数排序。点击线索可聚焦趋势、前期基准与近期区间，再进入相应专题核对证据；“并列对照”可恢复两条趋势。筛选后的演示估算与合成明细来源在比较依据中标明。试用转正解读与D页复用同一互斥分组贡献计算，直接给出主要分组及百分点贡献；其余分组存在变化时同时交代合计，保留数学分解不证明因果的边界。批次或分组样本不足30、变化基本持平或依据不一致时不生成强分组线索，不把变化乘单周分母当成实际损失人数。

指标口径：关键指标卡、目录和当前证据标题旁均可点同款弱化的i入口，显示原指标的定义、计算方法、数据粒度及来源。浮层保留浏览器顶层显示，宽度随文字尺寸变化，标题与关闭按钮固定、正文独立滚动；Esc或关闭回到原入口。原入口仍可见时不移动阅读位置，文字／窗口变化使其离开视口时再显露焦点；不改变筛选、证据、登记基线或草稿。

诊断阅读主语：A–G右侧优先解释当前左侧指标，登记入口标明同一指标编号与名称。已有可核验规则保留变化解读及计算依据；没有规则时仅显示事实摘要、统计窗口、适用筛选及已有历史变化，明确暂无诊断结论。其他指标的本页重点观察放在独立的“本页重点观察”展开入口，点击其证据后才切换阅读对象；查看证据不切换已有问题单。共享指标（如E页MRR）与本页自有指标的草稿、已保存问题均可在同范围问题选择器中找回，原基线及存储格式保持不变。

证据归属：当前指标的完整数据直接展示，旧专题补充表收在原生折叠的“专题补充参考数据”中，保留各自周期和分母。#18试用批次数据可用性仅在本指标默认展开；查看其他D页指标时作为标明#18的参考入口。G页查看#54质量计数时，#53异常发现清单另列折叠入口；选择#53时仍直接显示清单。查看参考不切换当前指标、既有问题单或草稿。#37首购与复购/续购摘要分别标注名称及人数；源汇总未明确月份，不计算月度变化或结构占比。

设备变化诊断：C页#42的“分组证据”先展示与右侧比较周期一致的互斥组合贡献，之后保留最新周的型号水平。默认前8周→近4周总体42%→58%，K6·固件2.8贡献+16个百分点、其他型号／固件组合0；选择统计周后改为相邻两周。贡献以同期总体触发数为分母，组内率与触发构成在独立验算入口核对；构成变化与组内变化采用两期平均权重分解，合计回到总体变化。观察链接直达分组变化证据，不更换既有问题单。上升空触发率标为不利；首周、缺少同范围计数或低样本分组不构造贡献。所有计数仍为合成样本，数学贡献不证明固件故障因果，也不把型号分配推广为真实经营判断。

专题观察：A、C、D 的比率比较展示前后值、百分点变化及可展开的周期和分子/分母。首页与专题共用按人数或事件次数合并的计算入口；专题选择统计周后比较相邻完整周，第一周或样本不足时不生成变化。估算范围与合成事实来源随筛选说明，不把跨期变化乘以单周分母写成实际损失人数。

图表核对：趋势末端与单序列分组柱直接标出数值；悬停保留单位，有逐周事实的比率同时显示分子、分母，并在完整数据表中给出相同依据。折线趋势按实际值域生成纵轴刻度，图下注明范围及非零起点；事件丢失率的默认演示范围为1.6%–2.4%，筛选后重新计算。普通比例分组柱保留零起点，按当前数据设置上限并注明范围，避免低比例被固定100%压平；同图各组共用刻度，隐藏系列不改变刻度，跨图比较需看实际比例而非柱高。指定刻度的技术图、100%结构图和热力图保留原规则。诊断工作区按趋势、分组与完整数据切换；图表下方可展开对应验算表，放大阅读或缩窄桌面窗口时按可用空间重新排列。100%结构图保持全部互斥类别展示，热力图统一使用0–100%色阶。

多系列图例：可切换的趋势/分组图例使用标准按钮，鼠标、Enter和空格均可显示或隐藏系列，按钮状态与ECharts保持一致。完整数据表和比较刻度不随隐藏操作改变；全部隐藏时明确提示恢复。折线以实线/虚线/点线与不同点形辅助区分；首页转正线在单独查看与并列对照中均保持绿色虚线。百分比堆叠图的固定状态图例继续不可切换，避免破坏100%结构解读。切换指标或业务筛选后图例恢复默认显示。放大桌面文字时侧栏宽度随文字尺寸增加，窄桌面窗口的首页趋势与分析转为单列，避免把图表挤窄；正常桌面的左右比例保留。

分类柱图按实际字体、文字放大比例与绘图区宽度判断标签是否能水平放下；短名称水平显示，保留显式指定的长标签角度，并按文字边界预留轴标签及图例空间。窗口或组件宽度改变后重新计算，不缩小字号，不改变类别、数值、零基线、图例选择或完整数据表。

订阅状态核对：D页#5直接打开两条产品线的当前状态100%堆叠图，与首页共用状态颜色和源人数。每条以自身主账号总数为分母，较大区段直接标占比；试用前期与临期在图中合并，完整值表分别保留。悬停及图表数据表显示精确状态人数与产品线人数，点击区段展开对应产品线验算行。缺数据或零总体不绘制已知比例，不以当前比例复制为历史。完整值表只移除整列空内容，保留有效数值、分子分母及文字；仅有结果的比例项明确说明没有同口径分子分母明细。

订阅状态历史：#5在“趋势与变化”补充12个UTC快照（2026-07-09至09-24），默认仍先看当前结构。可分别查看观鸟／狩猎的单个状态占比折线和同日期100%互斥状态条；完整数据按需展开24行人数。图点可定位对应日期验算行，显式选择的历史页签在刷新后保留。产品线／状态控件仅查看历史，不改变全局范围或问题单基线。

这12期是新增合成状态，付费总数和主账号池分别对齐原#2／#48历史，末期每项与当前快照相同。可重算范围内，#2付费历史改为同一状态之和，避免筛后独立取整相差最多2人；原总体12期及当前数值不变。国家／App／订阅平台沿用独立模拟分片，不代表真实交叉明细；型号／套餐缺历史归属时明确待补。快照变化不能作为逐用户转化、流失或原因；少于30人不绘占比，保留直接人数。源日期、分类或人数不闭合时仅暂停新历史，保留可靠当前结构及独立月度续订。`python3 scripts/generate_status_history.py`可确定性重建，`python3 scripts/verify_status_history.py`独立验算。

#5新问题登记在原基线文字中保存完整状态人数，默认折叠、可展开查看；人数变化时提示核对，更新处理进度不覆盖原计数。旧记录只有状态名称时说明无法自动判断变化，原编号、范围、基线、窗口和草稿不补写、不迁移。

未使用与回流：#29分别展示截至2026-09-24的当前未使用池，以及独立历史入组人群随后7天的回流；两行明确各自分母和窗口。历史入组日期未提供，不比较跨期趋势或归因召回效果。回流分母独立应用30人演示规则：少于30人保留人数、标为样本不足，零分母显示无历史样本，不影响仍有充分分母的当前未使用率。另一组600/5,000回流样例保持原人数，单独说明入组日期及回流窗口缺失；不与7天样例合并。问题登记继续使用当前未使用率与快照基线。宽表横向滚动时，标题、滚动提示与计算说明留在可视范围。

指标摘要：卡片主值明确标注统计对象和单位；累计注册与当前绑定、DAU与WAU/MAU、订阅ARPPU与月内付款人数、事件丢失率与ID映射覆盖率分别展示。目录和口径保留底表原名称；摘要与完整值跟随各自适用的筛选条件，不适用时不显示虚构人数。多设备主账号占比可进入12期趋势与验算表；多设备占比和共享率上涨仅标注变化，不自动判为改善。

付费价值变化：E页#35观察按最近两个完整月的订阅净收入比较。付款人数变化与ARPPU变化采用两期均值作对称算术分解，两项合计回到收入净变化；默认7月→8月为+$2,020＝人数项+$1,030＋ARPPU项+$990。观察可展开两期人数、收入与ARPPU，点击证据进入贡献柱图与验算表。贡献柱按增加／抵减／持平区分颜色，保留零基线，带符号金额标在各自柱端，并以文字说明方向。贡献不是价格或业务因果判断，与MRR分开；筛后仍为模拟分片估算，低样本或不支持范围不生成拆分。

总体月度留存：B页#24按2025-09至2026-08的12个完整自然月、96个互斥国家×基期App平台合成分组重算。留存人数除以上月复合活跃正式主账号人数；包含观察月未留存者，不用观察月活跃人数作分母，不平均分组率。相邻月份活跃人数接续；国家／平台归属在合成样例中固定，正式接入须确认基期归属。7／8月保留72.0%／77.1%，人数按已批准的总体方案改为48,960／68,000和54,000／70,000；“其他＋iOS”因整数闭合由73.6%改为73.7%。这次重建不表示真实经营增长，也不是逐账号事件日志。

“留存观察月（仅#24）”位于本项证据标题下，可恢复URL、刷新与前进后退状态；只更新本指标、证据和问题登记范围。其他B页指标保留各自窗口，原滚动MAU不改。趋势虚线标识所选月份，末端仍标最新完整月，完整表逐月列出基期月、观察月、留存／基期／观察月人数及留存率；与上期比较使用所选月的前一个完整月，最早月不补造比较。缺失、未完整、重复或无效月份显示待核验，可用月份控件修正，不回退为默认值或0；人数少于30时仅说明人数与样本不足。

8月默认范围与原问题编号兼容；其他月份独立登记，在现有基线文字内保存人数和两个月份。旧记录的范围、基线、编号和草稿不迁移、不补写人数，旧记录界面明确说明证据缺项；查看其他月份不切换已有其他指标的问题单。“已登记问题”恢复原月份及原记录。运行 `python3 scripts/generate_monthly_retention.py` 重建样例，`python3 scripts/verify_monthly_retention.py` 独立核对180种月份／筛选组合、2,160个历史点及异常来源；`scripts/verify_monthly_retention_flows.js` 验证浏览器操作、实际图表与旧记录保护。总体必要集合上界检查通过不等于逐账号来源链已验证。

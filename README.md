# Parallens 桌面数据看板原型

本仓库是静态网页原型，数据均为演示用模拟数据。当前分享地址：https://sailorxsh.github.io/parallens-demo/ 。

时间口径：完整周成熟批次为 W1–W12，截止 2026-09-13；当前经营快照截至 2026-09-24。历史经营快照是每隔7天构造的演示序列，不能当作 W1–W12 的实际批次历史。统计周仅显示在有周度事实的诊断页，不套用到快照指标。尚无可核验的任意日期区间事实，因此原型不提供自由日期范围。

首页变化线索：7日价值激活比较前8周与近4周，试用转正比较前9周与近3周；分别合并分子、分母后计算变化，不按跨阶段人数排序。点击线索可聚焦趋势、前期基准与近期区间，再进入相应专题核对证据；“并列对照”可恢复两条趋势。筛选后的演示估算与合成明细来源在比较依据中标明。

专题观察：A、C、D 的比率比较展示前后值、百分点变化及可展开的周期和分子/分母。首页与专题共用按人数或事件次数合并的计算入口；专题选择统计周后比较相邻完整周，第一周或样本不足时不生成变化。估算范围与合成事实来源随筛选说明，不把跨期变化乘以单周分母写成实际损失人数。

图表核对：趋势末端与单序列分组柱直接标出数值；悬停保留单位，有逐周事实的比率同时显示分子、分母，并在完整数据表中给出相同依据。折线趋势按实际值域生成纵轴刻度，图下注明范围及非零起点；事件丢失率的默认演示范围为1.6%–2.4%，筛选后重新计算。指标数据核对区的补充趋势、常规分组图与各自验算表并排呈现；放大阅读或缩窄桌面窗口时按可用空间重新排列。100%结构图保持全部互斥类别展示，热力图统一使用0–100%色阶。

指标摘要：卡片主值明确标注统计对象和单位；累计注册与当前绑定、DAU与WAU/MAU、订阅ARPPU与月内付款人数、事件丢失率与ID映射覆盖率分别展示。目录和口径保留底表原名称；摘要与完整值跟随各自适用的筛选条件，不适用时不显示虚构人数。多设备主账号占比可进入12期趋势与验算表；多设备占比和共享率上涨仅标注变化，不自动判为改善。

技术链路：上传、直播、推送独立展示成功率，默认主值明确标为三者最低；选择功能后只显示该链路。摘要和核对区给出各自请求数、成功数、失败数与失败率，柱图从0开始。型号×固件按最近24小时合成请求明细聚合，设备状态仍属模拟分片估算，分别说明来源；没有可比历史或生产目标时明确标注，不虚构趋势或达标结论。

数据质量入口：页头状态使用当前范围的#54指标计算；缺少筛后质量明细时显示“待补数据”，不会沿用总体的正常标记。默认范围以事件丢失率≤3%、ID映射覆盖率≥95%的演示阈值判定，明确标注“演示正常/演示预警”；缺少可核验比率或阈值时显示“待核验”。点击直接进入同范围质量指标证据，G页提供既有业务适用维度App平台的筛选入口，跳转保留平台选择；摘要与核对区说明阈值并区分生产标准。

质量指标证据同时呈现已有7日丢失率趋势和逐日丢失/预期事件数，悬停与表格使用同一分子、分母，纵轴按值域并注明非零起点。ID映射覆盖率只有当前快照，明确说明无可比历史；缺少同范围质量明细时仍显示待补数据，不拼接总体趋势。

桌面阅读：专题指标名称使用13px，变化提示、统计窗口、子项和摘要说明使用12px的相对字号。长名称平衡换行，详情为数值和说明分配更多宽度；浏览器不支持优化换行时保留普通换行。正常桌面仍并排呈现短指标，放大阅读时按可用宽度排列。

专题首屏：编号并入指标标题行，关键指标与主趋势区保留语义标题、去掉重复装饰编号，压缩页头和比较区的空白。默认1366×768、1600×900、1920×1080下可完整看到A–G的关键观察标题及A/C/D的前后率与百分点变化；保留原有字号、子项、口径入口和默认趋势，不要求全部图表挤入首屏。展开详情或筛选后的长说明可自然增加页面高度。

指标查找：保留底表名称和业务问题，同时识别卡片名称及DAU/WAU/MAU、技术链路、质量监控等子项。多个关键词以空格分隔共同匹配；全角编号和英文大小写统一处理。别名命中时显示匹配项，仍进入原指标证据并保留目标页支持的筛选；搜索不因当前筛选缺少数据而隐藏对应指标。

行动复查：点击指标摘要或数据核对中的“登记该指标问题”，显式打开当前指标＋筛选范围的问题单；查看辅助证据不自动切换。本范围的问题单可切换已有记录和未保存草稿，原记录键与历史基线保持不变。试用支付样本明确关联到试用转正问题单。清单条目分别关联对应指标依据；筛后核对表与卡片共用指标摘要，保留各子项名称、单位与窗口，点击指标可查看同范围证据。辅助证据跳转保留当前问题单和草稿。问题单按指标实际完整周、完整月或快照登记基线。登记与复查分组展示，人工确认通过需填写验收条件、实测值和实际复查日，不代表系统自动验算达标。记录仅存于当前浏览器，未保存内容切页暂存、刷新丢失；存储失败时保留原记录并明确提示失败，研判标记与问题单复查进度分开登记。

设备空触发：周×型号×固件合成事件计数是卡片、趋势、比较、分组和完整表的共同来源。原有每周总体与 K6 固件2.8 分组保留；其他型号拆分为构造样本，不作实测或因果结论。国家与季节仍为业务适用筛选，缺少交叉明细时显示待补数据。

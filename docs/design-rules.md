# Parallens 项目设计规范

本文件是项目设计的唯一维护入口。已确认，2026-10-21更新。设计和实现按本文执行；新的明确决定直接更新对应条目，不累积过程记录。验收证据另存验收报告。本文是执行标准，不表示所有页面已经完成验收。

## 1. 目标与范围

- 帮助用户完成“发现变化 → 核对证据 → 登记与复查”，兼顾可读性、效率、视觉辨识度和性能。
- 以Awwwards、Webby、FWA适合经营看板的品质方向作参照，不为装饰牺牲业务使用，不以测试数或迭代数证明达标。
- 只做桌面网页，不做移动端、不要求Safari验收。保留深绿品牌、紧凑自然符号页头和首页四模块顺序。
- 先统一A–G概览，再将同一套字号、配色、间距覆盖诊断页，不改变业务流程。

## 2. 信息与布局

- 核心数值、统计周期、变化和关键限制默认可见；低频明细按需展开。全部指标与完整数据始终可找到。
- 有可靠历史的核心指标默认展示趋势与比较；没有历史明确说明，不生成假趋势。
- A–G重点摘要在原数值旁显示已有变化及明确比较期，保留统计窗口；文字放大允许换行。缺可比数据不补造，C46多链路最低值不增加简化比较。
- 保留业务分组，允许调整组内顺序、列数和卡框。根据内容采用摘要带、趋势卡和宽证据图，不机械固定两列或强行等高。
- 阅读与诊断效率优先，不要求每页都更短。不通过缩小文字、隐藏关键口径或无意义留白换取整齐。
- 图形与对应摘要关联明确，提供直接定位；口径入口弱化、点击可查，浮层不能被其它内容遮挡。

## 3. 字体与间距

字体：本地DM Sans；中文使用PingFang SC／Microsoft YaHei等系统回退。字号使用rem，支持文字放大。

| 信息角色 | 标准字号（默认根字号16px） |
|---|---:|
| 页面标题 | 32px；紧凑页头28px |
| 业务分组标题 | 20px |
| 卡片／证据标题 | 16px |
| 正文与分析 | 14px，行高1.5–1.6 |
| 周期、分母、标签、辅助说明 | 12px；关键解释用14px |
| 主要指标数值 | 28–32px |
| 组合指标子值 | 18–20px |

间距以4px为基准，优先使用8／12／16／24／32px；卡片内边距16–20px，业务组间24–32px。同类组件共用规则，不逐卡随意调整。

## 4. 配色

核心要求是**适量亮色增强层次与辨识度**，不是只允许红色和橙色。禁用紫色；深绿保持品牌主色。

| 用途 | 表达规则 |
|---|---|
| 品牌、默认主趋势、选中 | 深绿；并列指标沿用固定身份色 |
| 主要文字与数值／辅助说明 | 深中性色／灰色 |
| 重点、需要关注 | 橙色等暖色小面积强调，同时有文字标识 |
| 明确失败或异常 | 红色；普通下降不自动判为异常 |
| 类别区分 | 绿、蓝、青、橙等；同维度跨页映射一致，保留直接标签与图例 |
| 连续数值 | 有图例的统一色阶；留存率用绿阶＋百分比 |
| 缺数、不适用、未成熟 | 中性状态与文字说明，不按0着色 |

固定身份色：激活率蓝、转正率深绿、空触发／事件丢失橙、异常发现红；普通主趋势默认深绿。系列色不代替阈值和风险结论，保留名称、线型或点形。订阅状态与留存色阶沿用原映射；实现入口为 `chartToneTokens`／`metricTrendTones` 和共享颜色变量。

亮色优先用于图形、线条、标记和浅底提示，不大面积铺满页面。蓝色、青色可用于中性类别，避免把所有类别都解释为风险。新增颜色须说明用途，并检查已有语义是否冲突。普通文字对比目标≥4.5:1，不只靠颜色传达含义。

## 5. 数据与交互

- 数值、图形、表格和结论来自同一筛选结果；周期、单位、分母明确。未知、不成熟、不适用与真实零分开。
- 图型按业务问题选择；清单用于查找、核对和操作，不能被图表替代。不同分母不强行比较，变化拆分不冒充因果。
- 保留筛选、深链接、浏览器前进后退、返回位置、历史问题编号、基线和草稿。历史证据按保存值只读呈现，优先复用可读表格；不依赖当前明细回填，无法识别时保留原文并说明。
- 已登记问题的保存详情在该记录下方整行展开，保留列表查找、排序和打开原问题单；放大后宽表按需滚动，查看不改写记录。
- 诊断优先解释当前指标；D18原位核对保留，C42不照搬该交互。
- #54保留当前范围整体判断，同时显露同日、同国家的 iOS／Android 分组演示预警及计数，并直达证据；已选单平台不重复提示，缺可靠来源或阈值不臆造判断。
- 保留按页加载与失败重试，初始传输目标≤700KiB，不为视觉引入不必要的重型资源。

## 6. 开发与验收

- 字号、颜色、间距使用共享样式变量；同类组件复用。颜色映射集中维护，禁止在业务组件中临时另选颜色。
- 验收1366／1600／1920桌面宽度和200%文字，检查溢出、遮挡、对比、键盘、图例与完整任务。根字号测试不等同所有浏览器缩放场景。
- 修改后检查筛选、诊断、返回及问题记录；用实际截图和行为验证，不以代码检查代替使用效果。
- 只处理有明确品质影响的问题；必要检查通过后收口，不无限零散微调。
- 已批准并应用本地：A–G概览的摘要／证据整合、订阅配色与固定筛选提示；诊断页的统一卡框、右侧解读／登记样式，以及F51／G54宽桌面双趋势并排。后续新的布局方案仍先独立预览，具体版本确认后实施。

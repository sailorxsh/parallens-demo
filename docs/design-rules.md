# Parallens 设计规范

用于日常设计与开发。仅保留当前规则，变更直接更新对应条目，不记录迭代过程。维护源：`planning/设计规则与约束复核.md`；仓库副本：`docs/design-rules.md`。

## 目标与范围

- 支持“发现变化 → 核对证据 → 登记与复查”，优先保证直观、易读、操作连贯和加载效率。
- 以 Awwwards、Webby、FWA 的设计品质为参照，视觉表达服务经营任务。
- 仅面向桌面网页；保留深绿品牌和紧凑自然符号页头，不做移动端适配，不要求 Safari 验收。

## 信息与布局

- 首页顺序固定：经营简报、经营结果、核心变化、六节点主线。
- 数值、周期、比较和关键限制默认可见；低频明细可展开，全部指标与完整数据可找到。
- 同一指标的数值、趋势、构成就近组织；按内容分配列宽，减少重复标题和嵌套卡框，不强求等高或每页更短。
- 标题是否跨列、两侧是否顶部对齐，以实际内容为准；不把单卡方案机械推广全站。诊断入口靠右下，不为定位额外拉高卡片。
- 有历史则默认显示趋势、比较期和变化；短趋势标明起止时间与观测点数。无可靠历史不生成趋势。
- 诊断优先解释当前所看指标，图形与证据入口相邻；口径使用弱化图标，点击后可完整阅读且不被遮挡。
- 文字放大允许换行和纵向排列，不缩小文字或隐藏关键信息。悬浮导航使用不透明底色，不遮住目标及键盘焦点。
- 保留各页业务分组及不同统计对象；B页连续分析区、E页独立指标单元不强制统一为同一模板。D续订组采用左23＋33、右52＋32；F49／G53跨列标题、C47／F47摘要与证据顶部对齐。

## 字体与间距

使用本地 DM Sans，中文回退 PingFang SC／Microsoft YaHei。字号用 `rem`，以下以根字号16px为基准。

| 信息角色 | 字号 |
|---|---|
| 页面标题 | 32px；紧凑页头28px |
| 业务分组标题 | 20px |
| 卡片／证据标题 | 16px |
| 正文与关键解释 | 14px，行高1.5–1.6 |
| 周期、分母、辅助说明 | 12px |
| 主要数值 | 28–32px |
| 组合子值／独立数值卡 | 18–20px／24px |

首页主要数值随宽度在32–44px变化；首页主趋势及D18／C42／E36主证据标题为1.65rem，不推广到所有首图。间距以4px为基准，常用8／12／16／24／32px；卡片内边距16–20px，业务组间24–32px。

## 配色

| 用途 | 规则 |
|---|---|
| 品牌、默认趋势、选中 | 深绿 |
| 正文与辅助说明 | 深中性色／灰色 |
| 重点、关注 | 小面积橙色等亮色，并有文字说明 |
| 明确失败或异常 | 红色；普通下降不自动判为异常 |
| 类别 | 绿、蓝、青、橙等固定映射，同维度跨页一致；禁用紫色 |
| 连续数值 | 同尺度、带图例；留存率使用0–100%绿阶与百分比，越高越深 |
| 持平、缺数、不适用、未成熟 | 中性色与文字，不按0着色 |

指标身份色：激活率蓝、转正率深绿、空触发／事件丢失橙、异常发现红。亮色用于图形、标记和浅底提示，不大面积铺满。普通文字对比度至少4.5:1；不只靠颜色表达含义，高对比模式保留数字与标签。

## 图形与数据

- 按比较、变化、关系、分布、构成、流转选择图型，比较合理替代方案与空间代价；不因上一项用了某图型就继续套用。
- 图表、数值、表格和结论使用同一筛选结果，明确周期、单位、分母与来源；不同统计对象不强行合并。
- 数量条从0开始；趋势轴可按数据留余量并清楚标示尺度。百分比不一律固定到100%，也不用填满的条冒充目标达成。
- 嵌套窗口、重叠类别与子集不相加或重复堆叠；变化贡献不解释为因果。缺数保留断点并说明原因，不补0；无可靠阈值不判异常。
- 保留精确值与可核对表格；名单、搜索和操作清单不能被图形替代。图例显隐不改变来源或尺度。
- 关键表达：A14以P50/P90点图为主、额外模拟箱线按需展开；E39用活跃率×订阅率等大散点，不添加虚构象限；D18区分总体贡献与组内变化，C42保留自身交互；F50共享为状态中的子集；B30组合互斥、来源可重叠。

## 交互、性能与验收

- 筛选作用范围明确；缺数、不适用、未成熟与真实零分开。不可用操作就近说明原因；空结果提供调整筛选入口，不自动改条件。
- 保留深链接、前进后退、返回位置与焦点。普通搜索保留筛选；明确功能名称搜索只切换对应功能。
- 查看指标不切换已有问题单，不覆盖编号、历史范围、首次基线或草稿；写入样本须显式操作，不自动保存。历史详情在记录下方整行展开，使用保存证据，不拿当前数据回填。
- 保留按页加载、加载反馈和失败重试；图形失败仍可读完整数据，重试不重建表单或丢失草稿。初始传输目标≤700KiB。
- 字号、颜色、间距复用共享变量；同类组件和颜色映射集中维护。
- 验收1366／1600／1920宽度及200%文字，检查真实截图、溢出、遮挡、图例、键盘、筛选、诊断往返及记录保护；文字放大不等同全部浏览器缩放场景。
- 只处理有明确使用或品质收益的问题，必要验证通过后收口。新的整体布局先做独立预览；应用与发布按明确授权执行。发布使用 GitHub Pages，Netlify 保留且不自动更新。

# Parallens 项目设计规范

本文件是项目设计的唯一维护入口。已确认，2026-10-26更新。设计和实现按本文执行；新的明确决定直接更新对应条目，不累积过程记录。验收证据另存验收报告。本文是执行标准，不表示所有页面已经完成验收。

## 1. 目标与范围

- 全局图形表达优化已全部验收采纳；继续原计划中的整体品质工作。普通修复自主实施验证，涉及核心流程或整体设计取舍时沿用大改动规则；发布单独授权。

- 帮助用户完成“发现变化 → 核对证据 → 登记与复查”，兼顾可读性、效率、视觉辨识度和性能。
- 以Awwwards、Webby、FWA适合经营看板的品质方向作参照，不为装饰牺牲业务使用，不以测试数或迭代数证明达标。
- 只做桌面网页，不做移动端、不要求Safari验收。保留深绿品牌、紧凑自然符号页头和首页四模块顺序。
- 先统一A–G概览，再将同一套字号、配色、间距覆盖诊断页，不改变业务流程。

## 2. 信息与布局

- 核心数值、统计周期、变化和关键限制默认可见；低频明细按需展开。全部指标与完整数据始终可找到。
- 有可靠历史的核心指标默认展示趋势与比较；没有历史明确说明，不生成假趋势。概览短趋势显示来源起止标签和观测点数，与当前指标统计窗口区分。
- A–G重点摘要在原数值旁显示已有变化及明确比较期，保留统计窗口；文字放大允许换行。缺可比数据不补造，C46多链路最低值不增加简化比较。 摘要标题同行显示“核对证据”入口，整块摘要保留单一诊断链接，进入和返回保留筛选与焦点。
- A／D摘要下补充已有的激活／转正跨期观察及证据入口，复用当前有效范围的两期计数；选定单周、缺少可靠比较或小样本时不显示，不新增异常判定。
- 保留业务分组，允许调整组内顺序、列数和卡框。根据内容采用摘要带、趋势卡和宽证据图，不机械固定两列或强行等高。
- B概览三个业务组采用连续分析区，以组内分隔线代替独立卡框；#27通知构成放入对应指标，保留完整表与诊断入口。此例外仅适用于B概览，不自动扩展其他页。
- E概览保留三个业务组与八项指标；#34付费权益、#3 MRR的数值、趋势和构成在各自分析单元连续展示，#35保留独立完整月口径。增值服务采用#37摘要带＋#36宽构成图；#38–40保留不同统计对象及原图形，不合并分母。
- 同一指标的摘要、趋势与构成共用分析单元；宽单元按内容分栏。F49／G53保留跨列标题，使两侧数据同起点；C47／F47等摘要与证据采用顶部对齐，不机械推广。诊断入口靠单元右下角，优先复用现有操作行，不遮挡内容或为定位无谓增高。
- 阅读与诊断效率优先，不要求每页都更短。不通过缩小文字、隐藏关键口径或无意义留白换取整齐。
- 悬浮证据导航与右侧内部切换栏使用与所在区域一致的不透明底色，遮住滚动经过的内容；表格中的证据跳转需将目标和键盘焦点定位到悬浮导航下方。
- 图形与对应摘要关联明确，提供直接定位；口径入口弱化、点击可查，浮层不能被其它内容遮挡。按钮与链接的辅助名称保留完整可见文字，指标等补充说明放在后面。

## 3. 字体与间距

字体：本地DM Sans；中文使用PingFang SC／Microsoft YaHei等系统回退。字号使用rem，支持文字放大。

| 信息角色 | 标准字号（默认根字号16px） |
|---|---:|
| 页面标题 | 32px；紧凑页头28px |
| 业务分组标题 | 20px |
| 卡片／证据标题 | 16px |
| 正文与分析 | 14px，行高1.5–1.6 |
| 周期、分母、标签、辅助说明 | 12px；关键解释用14px |
| 主要指标数值 | 28–32px |
| 组合指标子值 | 18–20px |

首页及全部诊断工作区采用连续分隔、浅底解读和统一定位／登记入口，减少外层嵌套卡框；内部图形、清单、表格和并列关系按业务保留。主证据标题仅在已确认的D18／C42／E36使用1.65rem，不按“首图”机械推广。首页主要数值使用 clamp(2rem, 1.4rem + 1vw, 2.75rem)，主趋势标题1.65rem；普通卡片标题保持标准字号。D18选中分组用深绿底、浅色文字和橙色边线，保留键盘焦点与文字标签，不复制到C42。

间距以4px为基准，优先使用8／12／16／24／32px；卡片内边距16–20px，业务组间24–32px。同类组件共用规则，不逐卡随意调整。

## 4. 配色

核心要求是**适量亮色增强层次与辨识度**，不是只允许红色和橙色。禁用紫色；深绿保持品牌主色。

| 用途 | 表达规则 |
|---|---|
| 品牌、默认主趋势、选中 | 深绿；并列指标沿用固定身份色 |
| 主要文字与数值／辅助说明 | 深中性色／灰色 |
| 重点、需要关注 | 橙色等暖色小面积强调，同时有文字标识 |
| 明确失败或异常 | 红色；普通下降不自动判为异常 |
| 类别区分 | 绿、蓝、青、橙等；同维度跨页映射一致，保留直接标签与图例 |
| 连续数值 | 有图例的统一色阶；留存率用绿阶＋百分比。A12／B28／C43概览有有效比率时显示0–100%图例；未成熟/不可用项不着色，全不可用不显示图例。系统高对比模式保留数字，隐藏失效的颜色图例 |
| 持平、缺数、不适用、未成熟 | 变化说明采用中性色；缺数不按0着色，保留文字说明 |

固定身份色：激活率蓝、转正率深绿、空触发／事件丢失橙、异常发现红；普通主趋势默认深绿。系列色不代替阈值和风险结论，保留名称、线型或点形。订阅状态与留存色阶沿用原映射；实现入口为 `chartToneTokens`／`metricTrendTones` 和共享颜色变量；类别配色统一通过 `categoryColorMap`／`categoryColor` 复用，概览、诊断与历史图同类同色。

亮色优先用于图形、线条、标记和浅底提示，不大面积铺满页面。蓝色、青色可用于中性类别，避免把所有类别都解释为风险。新增颜色须说明用途，并检查已有语义是否冲突。普通文字对比目标≥4.5:1，不只靠颜色传达含义。

## 5. 数据与交互

- 指标搜索覆盖页面可见名称与子项，别名说明统计范围，不新增指标。普通搜索保留筛选；完整搜索#27的“直播使用率／事件回看使用率／AI识别查看使用率”时，结果明示目标，点击后仅切换所看功能，保留其他受支持筛选、返回与原记录／草稿。
- 数值、图形、表格和结论来自同一筛选结果；周期、单位、分母明确。未知、不成熟、不适用与真实零分开。 不可用操作用中性色和可见原因说明，不能只靠悬停或点击失败表达。
- 选图先区分比较、变化、关系、分布、构成和流转；适合时主动考虑多维整合。图形沿用必须有当前比较任务的依据；变更前比较合理替代图型，检查阅读收益与空间代价，不把同类代码复用或上一轮采用当作设计依据。
- 图型按业务问题选择；清单用于查找、核对和操作，不能被图表替代。不同分母不强行比较，变化拆分不冒充因果。
- 当前指标无可用结果时，不显示空证据入口；有已选筛选或筛选错误时提供“调整当前筛选”，仅展开现有筛选区并移动焦点，不自动改条件；没有已选条件时保留状态与原因。有数据时保持原证据导航。
- 保留筛选、深链接、浏览器前进后退、返回位置、历史问题编号、基线和草稿。历史证据按保存值只读呈现，优先复用可读表格；不依赖当前明细回填，无法识别时保留原文并说明。
- 已登记问题的保存详情在该记录下方整行展开，保留列表查找、排序和打开原问题单；放大后宽表按需滚动，查看不改写记录。
- 诊断优先解释当前指标；D18原位核对保留，C42不照搬该交互。
- C42设备详情可显式将关联#42的样本编号填入问题草稿；不自动保存，不覆盖已有其他编号或其他指标草稿。保留所选设备、总体基线和比较证据，独立演示样本不作为总体计算依据。
- C41的近24小时／7天／30天设备数、D22的各项权益耗尽人数用同尺度横条，名称／图形／精确值同行且各行物理零点一致。保留C41主活跃率及趋势、D22去重并集与重叠说明。D20采用有明确刻度的点图，保留触点各自人数与百分点差异；两个点共用从0开始、留余量的显示范围，不用填满条表示转化率，也不固定拉到100%。显示范围不作为业务目标。
- B25概览以同尺度成对横条展示近1／7／30天复合与App活跃，保留日趋势；窗口嵌套不相加，App为子集不堆叠。D21概览将期初／期末／净增与正负流量条分开，保留闭合等式、当月截至日说明及诊断桥图。
- B30概览以左侧App／内容／推送矩阵配同轴数量条，组合名称、人数与占比贴近横条；七类互斥组合及固定配色保留，来源总人数可重叠，不相加。
- F50概览用同尺度互斥状态条表达设备数量，橙色斜纹表示其中共享子集；保留五项计数、缺失交叉状态及模拟分片限制，不把子集重复相加或推断设备迁移。
- D18按“总体变化→互斥贡献→组内变化”阅读：贡献行选择分组，转正率与支付失败率分别显示前后对照、变化量和计数；同指标组间保持刻度，两指标不按线长比较。宽桌面并排，文字放大按序排列；保留缺数、小样本与单周限制。
- #54主趋势有缺数时显示同源日期及原因，不补0或连线；超过两日时汇总天数，日期按需展开，无缺数不占位。
- #54保留当前范围整体判断，同时显露同日、同国家的 iOS／Android 分组演示预警及计数，并直达证据；已选单平台不重复提示，缺可靠来源或阈值不臆造判断。
- 图形资源失败时保留完整数据，并提供原位重试；恢复只绘制当前页面图表，不重建问题表单、不改筛选或保存记录。连续失败仍可重试，键盘焦点保留；切页后完成不拉回旧页。
- 保留按页加载与失败重试，初始传输目标≤700KiB，不为视觉引入不必要的重型资源。

- A14优先展示P50/P90刻度点图；额外模拟箱线按需展开。E39诊断用活跃率×订阅率等大散点，名称和人数可核对；不加虚构阈值象限或回归因果解释，概览保留紧凑扫描表达。
- A7分组用绑定/当前未绑定互斥数量堆叠；F51用同型号D7/D30成对数量比例条，未成熟留空，解绑率与操作表保留。长标签分类比较优先横条，不能因此把重叠类别堆叠；图例显隐不改变来源和尺度。

- A14、C08／C45、D33概览采用常规数值卡，周期、数值、限制及右下诊断入口保留；C页宽布局按内容三卡并排，窄容器自然换行。D页续订组采用左23＋33、右52＋32，短卡保留自然高度，不为齐底填充空白。

## 6. 开发与验收

- 字号、颜色、间距使用共享样式变量；同类组件复用。颜色映射集中维护，禁止在业务组件中临时另选颜色。
- 验收1366／1600／1920桌面宽度和200%文字，检查溢出、遮挡、对比、键盘、图例与完整任务。根字号测试不等同所有浏览器缩放场景。
- 修改后检查筛选、诊断、返回及问题记录；用实际截图和行为验证，不以代码检查代替使用效果。
- 只处理有明确品质影响的问题；必要检查通过后收口，不无限零散微调。
- 已批准并应用本地：A–G概览的摘要／证据整合、订阅配色与固定筛选提示；诊断页的统一卡框、右侧解读／登记样式，以及F51／G54宽桌面双趋势并排。本轮全局图形任务按最新自主授权执行；其他未授权范围仍先预览。
- 发布遵守项目授权：GitHub Pages管理发布，Netlify保留且不自动更新；设计调整不自动包含push或生产发布。
